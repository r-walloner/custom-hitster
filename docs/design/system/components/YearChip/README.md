# YearChip

A player's timeline in short form: just the years, in order, as small chips.

## Rules

- Use it where a whole board would be too big: the full scoreboard, one row of chips per player.
- `.jm-year-chip` is 12px/800 with tabular figures on `label`, outlined in `sand-line`; chips sit 4px apart and wrap.
- It's read-only. Titles and artists stay on the real cards.
